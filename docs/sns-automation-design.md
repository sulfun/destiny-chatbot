# 술술미 SNS 자동화 설계 v0.1 (2026-11-02)

> 이 브랜치는 **문서만** 추가합니다. 앱 코드(app.py 등)는 건드리지 않았습니다.

## 1. 목표와 원칙
- 목표: 인스타그램 · 유튜브(쇼츠) · 네이버 블로그 각 **팔로워/구독자/이웃 1,000명**
- 목적 지표는 팔로워가 아니라 퍼널: 노출 → 프로필/링크 클릭 → sulsul.me 가입 → 첫 결제
- **자동화 대상 = 제작·발행·측정.** 팔로우/좋아요/댓글 자동 봇은 쓰지 않음 (플랫폼 약관 위반 → 계정 정지·도달 제한 위험, 계정이 지하 명의)
- 외부 유료 업로드 서비스 없이 n8n 자체 운영
- 원고 최종본은 지하가 작성·승인 (자동은 초안까지)

## 2. 콘텐츠 1개 → 3채널 재활용
| 원본 | 인스타 | 유튜브 | 블로그 |
|---|---|---|---|
| 일주(일간)별 오늘의 운세 9:16 영상 (수진·똥그리 캐릭터) | 릴스 + 공유용 카드 이미지 | 쇼츠 (동일 영상) | 주 2회: 그 주 운세 묶음 + 개운법 글 (검색 유입용) |

- 훅: "○○일주, 오늘 이거 하면 술술 풀림" → 마지막 컷 "내 일주 확인은 프로필 링크(sulsul.me)"
- 인스타 공유 유도: 친구 일주 태그·스토리 공유용 카드

## 3. 파이프라인 (n8n)
```
[06:00 Cron] 오늘 날짜 → 일진 계산 → 일주 그룹별 운세 소재 (술술미 엔진/Supabase)
   → [LLM] 대본 초안 3안 생성
   → [Google Sheet '콘텐츠 큐'] 상태=검토대기  ──▶ 지하가 수정 후 상태=승인
[승인 트리거] → 영상 렌더 (캐릭터 PNG + 자막 + BGM, ffmpeg/Remotion 템플릿)
   → Supabase Storage 업로드 (공개 URL)
   → 예약 시간에 채널별 발행
       ├ YouTube Data API videos.insert (쇼츠)
       ├ Instagram Graph API (릴스 컨테이너 생성 → publish)
       └ 블로그: 원고+이미지를 Drive/Notion 초안으로 → 지하가 예약발행 (반자동)
[매주 월 08:00] 채널별 팔로워·조회·클릭 수집 → 대시보드 '입력_채널' 탭 자동 기입
[매일 21:00] 미답변 댓글 목록 → 지하에게 알림 (답글은 사람이 직접)
```

## 4. 채널별 사전 조건 · 주의
- **인스타**: 프로페셔널(크리에이터/비즈니스) 계정 + 페이스북 페이지 연결 + Meta 앱 필요. 영상은 공개 URL에서 가져가므로 Storage 공개 버킷 필요. API 게시 횟수 일일 한도 있음.
- **유튜브**: Google Cloud 프로젝트 + OAuth. 미검수 API 프로젝트로 올린 영상은 **비공개로 고정**되므로 API 감사(audit) 신청 필요 → 승인 전까진 업로드만 자동, 공개 전환은 수동.
- **네이버 블로그**: 글쓰기 공식 API를 전제로 하지 않음. 완전 자동 발행 대신 초안 자동 생성 + 사람이 예약발행. 기계적 반복글은 저품질 판정 위험.

## 5. 발행량 (대시보드 설정 기준 + 조정안)
| 채널 | 현재 계획 | 1,000명 목표용 제안 |
|---|---|---|
| 인스타 | 주 7 | 릴스 주 7 + 스토리 매일 |
| 유튜브 쇼츠 | 주 3 | 주 7 (같은 영상 재사용이라 추가 비용 거의 없음) |
| 블로그 | 주 2 | 주 2~3 |

## 6. 팔로워 성장 레버 (자동화 밖, 사람이 할 일)
1. 첫 3시간 댓글 답글 (알고리즘 초기 반응)
2. 크리에이터 시딩 10명 (실험 로그 '대기' → 착수)
3. 기존 가입자·네트워크에 계정 팔로우 안내 (초대 메일에 링크 추가)
4. 주 1회 성과 상위 영상 포맷 복제

## 7. 측정 & 판단 기준
- 주간: 팔로워 증가, 조회/도달, 링크 클릭, UTM 가입 (대시보드 C블록)
- 4주차 점검: 주당 팔로워 증가 < 50이면 훅/포맷 교체, 발행량은 유지
- UTM: `?utm_source=instagram|youtube|naverblog&utm_medium=social&utm_campaign=daily_unse`
